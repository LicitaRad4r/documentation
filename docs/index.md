# LicitaRadar 

## A OPORTUNIDADE CERTA, ANTES DO PRAZO.

O **LicitaRadar** é uma plataforma desenvolvida para simplificar e otimizar a jornada de participação em editais públicos (PNCP) para Pequenas e Médias Empresas (PMEs). 

O nosso foco é fornecer uma triagem inteligente de oportunidades e garantir a segurança e conformidade documental das organizações.

## Sobre o Projeto
Este projeto está a ser desenvolvido como parte do **AI Lab (Makers Ciclo 1)** na Universidade de Brasília.
